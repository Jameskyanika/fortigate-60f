# FortiGate 60F Enterprise Firewall Portfolio

This repository documents practical enterprise firewall administration performed using FortiGate 60F firewalls.

The projects demonstrate real-world experience with:

- Multi-WAN configuration
- Firewall policies
- NAT
- VLAN segmentation
- ISP migration
- Internet failover
- Security hardening
- Enterprise troubleshooting

All configurations, screenshots and diagrams have been sanitized to protect production environments.
